# Lucid Studios Website

A static website for Lucid Studios — a code + game development studio.

## Run locally
Open `index.html` in a browser.

## Put it on GitHub Pages
1. Create a GitHub repository, e.g. `lucid-studios`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save. GitHub will give you a Pages URL.

## Customize
- Change project names/descriptions in `index.html`.
- Change colors and layout in `style.css`.
- Replace the GitHub link with your actual Lucid Studios GitHub organization/repository.
- Replace `hello@lucidstudios.dev` with your real studio email if you use one.

No framework, build system, or backend is required.
